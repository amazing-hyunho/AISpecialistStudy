## 2. 복기 내용과 현재 `Study` 자료 간 차이점 및 시험 대비 포인트

1. **4월 2차 `LoraConfig 선언` vs 직접 구현 LoRA**
   - `Study/LLM/Chapter_6_Excercise_Finetuning_Classification_LoRA.ipynb`에는 HuggingFace `peft`의 `LoraConfig`가 없고, `LORA_RANK = 16`, `LORA_ALPHA = 16` 상수 선언과 `LoRALayer`·`LinearWithLoRA`·`replace_linear_with_lora` 직접 구현이 수록되어 있습니다.
   - 만약 시험에서 강의 노트북 그대로 출제된다면 `LoRALayer`(`self.A`, `self.B`, `(self.alpha / self.rank) * (x @ self.A @ self.B)`)와 `replace_linear_with_lora(model, rank=LORA_RANK, alpha=LORA_ALPHA)`를 채우면 되고, 만약 `peft.LoraConfig`가 주어진다면 문제 가이드/주석에 제시된 인자(`r`, `lora_alpha`, `target_modules`, `lora_dropout`, `bias`, `task_type`)를 연결하면 됩니다.

2. **4월 2차 `vision: DETR Transformer (MultiHeadAttention forward, EncoderLayer forward)`**
   - `Study/Vision/03_DETR.ipynb`는 `torch.hub.load`로 사전학습 모델을 불러와 추론·박스 변환·hook 시각화를 수행하므로 내부 Transformer 클래스 정의가 없습니다.
   - `Study/Vision` 내에서 `MultiHeadAttention.forward`와 `EncoderLayer(Transformer).forward`를 직접 구현한 코드는 **`Study/Vision/02_ViT_CIFAR10.ipynb` Cell 8**(`Attention.forward`의 `to_qkv` → `chunk(3, dim=-1)` → `rearrange` → `einsum` → `to_out`, 그리고 `Transformer.forward`의 `x = attn(x) + x`, `x = ff(x) + x`)과 **`Study/LLM/Chapter_3_Excercise_Attention.ipynb` Cell 3**(`MultiHeadAttention.forward`)입니다. 두 셀의 텐서 흐름을 모두 숙지해 두면 어느 쪽으로 나와도 즉시 대응할 수 있습니다.

3. **On-device Pruning 3종(Fine-grained vs Kernel-level vs Channel-level) 비교 암기**
   - **원소 단위 (Cell 29)**: `num_elements = weight.numel()`, `importance = torch.abs(weight)`
   - **커널 단위 (Cell 33, 4월①·6월)**: `num_kernels = weight.shape[0] * weight.shape[1]`, `importance = weight.abs().sum(dim=(2, 3), keepdim=True)` → shape `(C_out, C_in, 1, 1)`
   - **채널 단위 (Cell 35, 5월·9월)**: `num_channels = weight.shape[1]`, `importance = weight.abs().sum(dim=(0, 2, 3), keepdim=True)` → shape `(1, C_in, 1, 1)`
   - 세 함수 모두 `num_pruned = round(개수 * sparsity)` → `threshold = torch.kthvalue(importance.flatten(), num_pruned)[0]` → `mask = importance > threshold` → (커널/채널의 경우 `mask = mask.expand_as(weight)`) → `weight.mul_(mask)` 패턴이 동일합니다.
