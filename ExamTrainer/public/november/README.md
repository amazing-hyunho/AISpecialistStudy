# 11월 대비 모의고사

1회는 먼저 준비할 후보, 2회는 다음 후보를 연습합니다. 각 60분·25빈칸·100점이며 회차별로 5과목에서 5빈칸씩 출제합니다. 실제 출제 확률을 수치화한 자료는 아닙니다.

| --- | --- | --- |
| 1회 · 우선 후보 | [문제](mock-1.md) | [정답·해설](mock-1-answers.md) |
| 2회 · 다음 후보 | [문제](mock-2.md) | [정답·해설](mock-2-answers.md) |

기존 강의 기반 문제은행과 10월 복기 정리를 사용했습니다. 같은 셀의 선택된 빈칸을 함께 가리고 전체 셀을 보존합니다. 두 회차의 문항 ID는 중복되지 않으며, 기존 웹 모의고사와 겹치는 연습 문항은 있습니다.
