# 월별 복기·예상 주제 문제은행과 모의고사

2026-10-26 개편. 기존 고정 10회와 랜덤 10셀 모의고사를 삭제했다.
현재 진입점은 `/exam-prep/`, 구성 원본은 `app/exam-prep/data.ts`이다.
기존 강의 문제은행과 사용자 학습 기록은 유지한다.

## 문제은행

- 월별 5개: 4월 1차 53문항, 4월 2차 68문항, 5월 46문항, 6월 46문항, 9월 40문항.
- 예상 주제 24개: LLM 6개, RAG 3개, Data 6개, Vision 5개, On-device 4개.
- 중복 제외 171문항. 강의 코드와 원본 실습 ???? 빈칸을 사용한다. 실습 빈칸 답안은 해설 답안으로 구분하며 신규 모델 구현 예제는 사용하지 않는다.
- 각 문항은 객관식 선택·확인 → 보기 접기 → 같은 빈칸 주관식 작성·채점 순서다.
- 회차·주제 사이에 같은 문항이 재사용되며 학습 진행은 각 세트별로 저장한다.

## 모의고사

- 월별 복기 5회: 각 월별 문제은행의 모든 문항을 주관식으로 출제한다. 실제 시험 문항 수의 복원이 아니다.
- 예상 3회: 매회 25문항, 다섯 과목 각 5문항. 총 75문항은 회차 간 중복이 없고 24개 대비 주제를 모두 포함한다.
- 1회: MHA·GPT, 검색·KG, window·Conv1D·학습·RNN, ResNet·전처리·평가·학습, kernel·channel·양자화·증류.
- 2회: DPO 데이터·모델·LoRA 설정·분류, KG·MCP, NGCF·NCF, DETR 추론·ViT Attention·residual, pruning·양자화·증류.
- 3회: 생성·학습·DPO 데이터·LoRA, 검색·prompt·MCP, window·Conv1D·Seq2Seq·추천, 분류·Attention·학습, pruning·재양자화·증류.
- 제출 전 정답·해설 비공개, 제출 후 답안 잠금·전체 및 과목별 점수·오답 필터·재응시 제공.
- 모든 문항은 같은 배점. 미입력도 오답이다.

## 근거와 제한

월별 범위는 사용자 복기에 근거한다. 9월 원문은 `app/exam-recall/original.ts`를 보존한다.
반복 또는 9월 상세 구현을 우선, 한 회차에만 명시된 주제를 보완으로 분류한다. 통계적 출제 확률이 아니다.

## 전체 셀 풀이 방식

- ±5줄 절단을 제거했다. 셀 상단 선언부터 마지막 줄까지 모두 표시한다.
- 같은 원본 셀의 선택된 문항은 한 셀 안에서 동시에 빈칸으로 가린다. 아직 출제하지 않은 다른 문항의 코드는 원문대로 남긴다.
- 객관식은 선택한 빈칸을 대상으로 풀고, 확인 후 해당 위치에서 직접 작성한다. 다른 빈칸을 선택해도 작성한 답은 유지한다.
- 모의고사는 현재 셀의 모든 출제 빈칸을 동시에 입력한다. 제출 후에만 답안·해설을 공개한다.
- 현재 빈칸 이동 버튼과 코드 내부 스크롤로 긴 셀의 위아래 흐름을 확인한다. 노트북의 다른 셀까지 합치지는 않는다.
- DPO의 실습 답안은 원본에 이미 적힌 정답으로 주장하지 않는다. 원래 ???? 위치의 해설 답안이며 별도 보충 구현이 아니다.

## 객관식 미리보기와 단축키

- 객관식 보기 전에 현재 빈칸 앞뒤 코드 미리보기를 표시한다. 같은 셀의 다른 출제 빈칸도 가린다.
- 미리보기는 보조 화면이며 아래 전체 셀은 생략 없이 유지한다.
- 객관식 단계에서는 숫자키 `1`·`2`·`3`·`4`(또는 마우스 클릭)로 보기를 선택해 정오답을 즉시 확인하고, 그 후 `Ctrl+Enter` 또는 `Cmd+Enter`를 누르면 같은 빈칸의 주관식 입력칸으로 이동한다.
- 주관식 연습의 입력칸에서 `Ctrl+Enter` 또는 `Cmd+Enter`로 해당 빈칸을 즉시 채점한다. 입력칸 옆에 결과가 표시되고 수정하면 다시 채점할 수 있다.
- 빈 입력·IME 조합 중·키 반복 이벤트는 채점하지 않는다. 모의고사는 기존 일괄 제출 후 채점 방식을 유지한다.
- 주관식 정답 확인 후 입력칸이나 다음 버튼·화면 어디서든 `Ctrl+Enter` 또는 `Cmd+Enter`를 다시 누르면 다음 문항으로 이동한다. 오답은 재채점하며, 답안을 수정하면 먼저 새 답안을 채점한다. 마지막 문항에서는 이동하지 않는다.
