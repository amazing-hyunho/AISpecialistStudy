# PDF 기준 고정 모의고사 10회분

기준 문서: `Study/AI인증시험_출제포인트.pdf` (2026년 3월 시험용 출제 포인트 표).
2026-09-14 현재 강의 문제은행에서 중요 흐름을 선별했다. 새로운 공식 기출이나 출제 확률 예측이 아니다.

## 선별 기준

- 매 회차 10셀, LLM·RAG·Data·Vision·On-device 각 2셀. 한 회차 안에서는 셀이 중복되지 않는다.
- 모델 입력·주요 layer·손실·갱신, RAG 검색·프롬프트·응답, 데이터 변환·평가지표, 양자화·프루닝·증류처럼 흐름을 구성하는 셀을 우선한다.
- 강의 설정값 하나나 import만 묻는 셀보다 실제 계산과 API 연결이 들어 있는 셀을 우선한다.
- 핵심 셀은 여러 회차에 반복한다. 예: 벡터 검색·프롬프트, 이미지 전처리·분류 학습, teacher/student 증류.
- 여러 구간을 합친 `dpo-completions`는 제외한다. DPO의 실제 모델·토크나이저 로드 셀 및 실제 LoRA 구현은 포함한다.
- 기존 문제·정답은 수정하지 않는다. `app/fixed-exams.ts`의 대표 문제 ID는 셀 선택을 위한 참조이며, 그 셀에 등록된 모든 빈칸이 출제된다.

## 회차별 목표

| 회차 | 목표 |
| --- | --- |
| 1 | 기본 입력→검색·학습 흐름, 양자화·프루닝 기본 |
| 2 | Attention·RNN·ViT 레이어, 문서 분할, 표현과 증류 |
| 3 | 예측·정답·손실·역전파·평가, 검색에서 생성까지 |
| 4 | 패딩·시프트·정규화·분할·증강·정확도 |
| 5 | DPO 모델 로드·LoRA, KG, 그래프 추천, WANDA·SmoothQuant |
| 6 | LoRA 보정·패딩 마스크, KG 분기, encoder-decoder, 특징 증류 |
| 7 | MCP Client→도구→Agent, 생성·학습, metric·재양자화 |
| 8 | Attention·GPT, Chat Completion·MCP, Conv1D·Seq2Seq, 확산·경량화 |
| 9 | 모델 로드·LoRA·벡터 검색·프롬프트 핵심 재암기 |
| 10 | 주요 모델·학습·KG·MCP·데이터·증강·프루닝·증류 종합 |

10회 전체에서 PDF의 LLM 모델/데이터, RAG 흐름/library, Data 모델/데이터/library/metric,
Vision 모델/학습/데이터/transforms/metric, On-device 양자화/프루닝/증류 축을 다룬다.
모든 강의 내용이나 모든 API를 망라하는 세트는 아니다.

## 연습 방법

1. 1~10회를 순서대로 풀고 제출 후 코드 옆 정답·해설을 확인한다.
2. 틀린 셀은 코드가 연결되는 순서를 읽은 뒤 같은 회차를 다시 푼다.
3. 마지막 복습은 9~10회와 오답노트를 활용한다. 실제 시험 범위 전체를 보장하지 않는다.

기존 랜덤 모의고사는 그대로 유지된다. 고정 모의고사의 재시작은 동일 셀·동일 빈칸으로 초기화되며,
진행 중 답안은 새로고침 시 저장되지 않는다. 제출 후에는 오답노트에 연동되고 다음 회차로 이동할 수 있다.
채점은 공백·들여쓰기를 허용하는 강의 정답 토큰 비교이며 동등한 다른 구현을 실행해서 판별하는 방식은 아니다.

검증: `node scripts/test-inline-quiz.cjs`에서 10회 구성·과목 균형·빈칸 수·재시작·다음 회차와 기존 랜덤 모드를 검사한다.
